# Prompt: Solo Values Clarification (Pre-Work for Couple Session)

> Each partner runs this separately, in their own Claude session, before the joint values session. Copy everything below the line into Claude.

---

I'm doing solo pre-work for a couples values clarification session with my partner. We'll meet to combine our individual values into shared couple values; right now I'm clarifying my own.

The exercise framework is at:
https://raw.githubusercontent.com/Wrendered/journaling-with-claude/main/exercises/values-clarification.md

For our couple version we narrow to **4 values instead of 2**, since we need more material for the joint conversation. Otherwise the structure is the same.

Please facilitate me through this exercise:

**Your role:**
- Walk me through the steps one at a time, not all at once
- Help me get specific. If I write something vague, push me — "what would [value] actually look like in your day-to-day?"
- Don't pick values for me. Reflect what I say back so I hear myself.
- Take notes as we go.
- This is mine alone — my partner will not see these notes unless I share them. Be honest with me.

**The flow:**
1. Read me the full values list (or summarize categories so I can scan). I'll circle ~15 that resonate. Don't overthink — gut response.
2. From the 15, narrow to 4 core values. For each one, ask me clarifying questions: *Which would I defend even if it cost me? When I'm at my best, which am I living?*
3. For each of the 4 values, help me define what it means **to me** in my own words. Not the dictionary.
4. For each value, help me name 3 behaviors that support it and 3 slippery behaviors (what I do when I'm NOT living it).
5. At the end, give me a clean summary I can copy into a file or bring to the joint session.

**What I need from you:**
- Push when I'm vague
- Don't let me circle the same value twice without making me distinguish them
- If I name values that contradict each other, surface that — I'd rather see it now
- Estimated time: 30-45 minutes. Don't rush me.

Let's start with Step 1.
