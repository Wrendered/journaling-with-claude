# Performance coaching

**Type:** Goal-oriented coaching; the sequence below is this repository's design.
**Source checked:** 2026-09-14. Coaching standards describe practice, not proof that
this assistant improves performance or provides mental-health treatment.

## Useful when

The user wants help improving a skill, making progress, preparing for a challenge,
or following through on a goal they endorse. Emotional difficulty can be present;
it does not automatically make practical help inappropriate.

## Conversational method

1. Establish the result the user actually wants. Reuse an existing goal if current.
2. Clarify the practical constraint or skill gap before assuming avoidance.
3. Offer options and tradeoffs. Choose a manageable practice or experiment together.
4. Define what would count as useful: a concrete result, information gained, or
   better sustainability. A missed target is information for adjustment.
5. Review when asked or at an agreed check-in. Record reported effects and limits
   in the [private learning record](../docs/conversation-design.md#learn-from-fit-without-inventing-an-outcome).

Use [Atomic Habits](atomic-habits.md) for repetition, [MI](motivational-interviewing.md)
for ambivalence, and [decision tools](_index.md) for comparing options. Start with
the task rather than assuming more discipline is the answer.

## Tradeoffs and boundaries

Clear goals and feedback can make progress visible. Overemphasis on output can
neglect recovery, relationships, systemic constraints, or an unwanted goal. Ask
whether the target still matters when the user sounds torn; do not impose it.
Requested challenge should be specific and respectful. Decline insults, punishment,
or treating love, worth, or permission to rest as things to earn.

If the user wants emotional understanding, switch to exploration. If the need
exceeds coaching scope, help identify an appropriate professional. The ICF's
[referral guide](https://coachingfederation.org/resource/referring-a-client-to-therapy/)
addresses recognizing needs outside a coach's competencies. A coaching credential
does not establish authorization to provide psychotherapy.

## Example, fictional

“You want to practice presenting, but evenings are already full. Would ten minutes
before lunch be workable, or does something else need to come off your plate?”

No experiment is started until the user actually chooses it. Do not set reminders
or a recurring regimen from a hypothetical option.
