# Start Day

Read [the shared memory contract](../../../docs/memory-contract.md) before the first capture, state update, or import in a session. Use AGENTS.md for privacy, attribution, and current-context precedence.

1. Read personal preferences, current context, and dashboard active tasks. Capture the user’s message first.
2. Ask how they are doing and what deserves their attention today. One prompt is enough when their capacity is low.
3. Follow configured morning rituals only if useful today. Do not force a mood score, streak, or productivity exercise onto a painful moment.
4. If a task connector is already configured, read relevant tasks. Create or change external tasks only within the user’s requested scope; do not send messages to other people.
5. Capture their responses exactly. Update dashboard tasks from explicit commitments, with source links. Do not infer completed habits from missing entries.
6. Rebuild views; keep the visible response short.
