# Add Framework

Read [the shared memory contract](../../../docs/memory-contract.md) before the first capture, state update, or import in a session. Use AGENTS.md for privacy, attribution, and current-context precedence.

1. Establish what the user wants to understand and check the existing library for overlap. Capture personal reflection privately.
2. For an unfamiliar framework, use bounded parallel research agents to check independent primary sources when available. Give each a distinct question; do not duplicate the same research. If unavailable, research directly. Distinguish evidence, author claims, and your interpretation; never confabulate citations.
3. Route the reference to frameworks/ for lenses, assessments/ for quizzes, daily-practices/ for recurring prompts, or exercises/ for deeper guided work. Keep it concise with purpose, how to use, limitations, primary links, and checked date.
4. Public references contain no personal examples, scores, names, or history. Personal application belongs in private/assessments/ or another appropriate wiki page, linked to actual source records.
5. Offer one optional experiment when useful. A model interpretation does not become a self-map fact because it was written down. Record user adoption separately and avoid diagnostic claims.
6. Update the appropriate library index, check links and public privacy, and rebuild private views if private links changed.
