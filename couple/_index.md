# Couple — Joint Exercises

> Structured exercises for romantic partnerships: building shared values, stress-testing alignment, working through transitions.
>
> **Safe to share with a partner.** Nothing in this folder references individual private content. Pair this folder with `exercises/` for individual prep work.

## Available Exercises

| Exercise | Purpose | Time | Pre-work |
|----------|---------|------|----------|
| [Values Clarification — Couple](values-clarification.md) | Build 3 shared couple values from individual lists | 90 min joint | Each partner does [individual values clarification](../exercises/values-clarification.md), narrowing to 4 values |
| [Pre-Commitment Conversations](pre-commitment-conversations.md) | Eight structured conversations (Gottman *Eight Dates*) to stress-test alignment on the concrete dimensions of long-term partnership | 8 sessions, weekly or biweekly | Solo prep before each session |

Use as warm-up if you've been feeling emotionally distant. Different purpose than compatibility-testing — pure intimacy-building through mutual self-disclosure.

## How to Use This Folder

**Suggested order:**

1. **Values Clarification — Couple** first. Builds the abstract compass: "what matters to us."
2. **Pre-Commitment Conversations** second. Tests whether the compass points at the same real-world life: kids, money, location, sex, family, growth, dreams.

You can do either independently, but together they're more useful than either alone.

**Want Claude as a facilitator?** See [`guided/`](guided/_index.md) — copy-paste-ready prompts that turn each exercise into a Claude-guided session, both for solo prep and joint work. Includes built-in "step away from the screen and just talk" moments.

## Principles

- **Pre-work matters.** Most of these exercises ask each partner to think alone first. Don't skip that step — it's how you avoid one person dominating the conversation.
- **Listening rules.** When your partner is speaking, you listen. No rebuttals, no problem-solving in the moment. Ask clarifying questions only.
- **Misalignment is data, not failure.** The point isn't to prove you're compatible. It's to know where you actually stand so you can decide consciously.
- **Sources are listed.** Each exercise cites where it came from — Gottman, Brené Brown, ACT, Finkel, etc. Useful if you want to go deeper.
