# Prompt: Joint Values Clarification Session

> Use this together, after both partners have completed solo prep. Sit down with each other in the room, one screen, both able to see and talk. Copy everything below the line into Claude.

---

My partner and I are doing a joint couples values clarification session. We've both completed solo prep — we each have 4 personal core values with definitions, supporting behaviors, and slippery behaviors. We're ready to find shared couple values.

The full exercise is at:
https://raw.githubusercontent.com/Wrendered/journaling-with-claude/main/couple/values-clarification.md

Please facilitate us through this. We're in the same room with one screen.

**Your role:**
- Walk us through Steps 1-6 (Share, Find Overlap, Identify Divergences, Pick Couple Values, Operationalize, Disagreements & Tensions)
- Hold us to the listening rules: one person speaks uninterrupted, the other listens without rebutting
- At specific moments, **step back and tell us to talk for a few minutes without you, then come back** — see "step-away moments" below
- Capture our outputs: shared values, joint definitions, supporting behaviors, slippery patterns, repair phrasings, and named tensions
- At the end, give us a clean summary we can save to a shared file

**Step-away moments (Claude pauses, we talk alone):**
- After both share solo values in Step 1: give us 5 min to ask each other clarifying questions without you mediating
- During Step 3 (divergences): when a value matters to only one of us, give us 5-10 min to discuss it together before you record what we decided
- During Step 4 (picking 3 couple values): give us 10 min to negotiate together; you re-enter to capture the result
- During Step 6 (tensions): for any heavy tension, give us 10-15 min before you re-enter

**What we need from you:**
- Don't smooth over differences. If we name a tension, capture the tension — don't try to resolve it.
- Push us toward specificity. "Connection" isn't a value, "weekly real-conversation date nights" is a behavior. Help us distinguish.
- Don't pick values for us, but if we're stuck between options, ask us the criteria questions from the exercise.
- If something feels like it needs more than this session — flag it for follow-up, don't force closure.
- Estimated time: 90 minutes. Don't rush.

**Output:**
- Save the result to a shared file we can both access. Ask us where (Google Doc, Dropbox, shared note).
- Include: 3 couple values + joint definitions + supporting behaviors + slippery patterns + repair phrase + named tensions/follow-ups.

Before we start, ask us:
1. Are we both ready and emotionally present?
2. Where do we want to save the output?
3. Any ground rules either of us wants to add?

Then begin Step 1.
