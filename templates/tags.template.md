# Tags

> Controlled vocabulary for `tags:` frontmatter. Cap at ~20 to avoid taxonomy rot.

## Active tags

Edit this list as your life evolves. Don't let drift create `career`, `career-move`, `career-project-x`, etc. — pick one level of granularity and stick to it. Tag drift is the most common Obsidian failure mode.

| Tag | What it covers |
|-----|----------------|
| `career` | Anything about job, work direction, professional identity |
| `relationship` | Romantic relationship, current or considering changes |
| `family` | Family of origin, siblings, parents |
| `friendship` | Close friendships, dynamics |
| `health` | Physical health, exercise, sleep, food |
| `mental-health` | Therapy, anxiety, depression, mood patterns |
| `money` | Financial decisions, anxiety, planning |
| `creative` | Writing, art, projects |
| `learning` | What I'm reading/studying |
| `decision` | Currently weighing a choice |
| `pattern` | Recurring theme, watch this |
| `win` | Something that worked |
| `block` | Something that's stuck |
| `gratitude` | Positive entries |
| `shame` | Shame surfaced (CBT/Brené Brown lens) |
| `parts` | Parts work (IFS lens) |

## Conventions

- Lowercase, kebab-case (`mental-health`, not `MentalHealth` or `mental_health`)
- No nested tags (`career-project-x` is a sub-bucket — instead, put `tags: [career]` and `topic: project-x` in frontmatter)
- Tags in frontmatter ONLY, never inline `#tags` in body text
- Add a tag here BEFORE using it the second time
