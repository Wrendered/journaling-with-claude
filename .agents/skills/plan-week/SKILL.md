# Plan Week

Read [the shared memory contract](../../../docs/memory-contract.md) before the first capture, state update, or import in a session. Use AGENTS.md for privacy, attribution, and current-context precedence.

1. Capture the request and read current context, dashboard, and relevant goals/decisions. Check dates before treating an old deadline as active.
2. Ask what matters this week and what capacity the user has. Prefer a few explicit commitments to an exhaustive schedule.
3. Connect priorities to source-backed goals, career plans, writings, and projects through existing wiki pages. Keep suggestions separate from accepted commitments.
4. Update dashboard with the commitments the user chose, dates they actually supplied, and links to sources. If a configured task connector is useful, act only within the requested scope.
5. Save new user messages unchanged, optional delivered planning summaries separately, and rebuild views. Leave unscheduled work unscheduled; do not invent deadlines.
