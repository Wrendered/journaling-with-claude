# Journal

New source messages live in entries/YYYY-MM-DD/ with exact text and attribution metadata. Use the shared capture tool rather than editing these files directly.

- [Timeline](../views/timeline.md)
- [Current context](../views/current.md)
- [Weekly reviews](../reviews/)

Existing YYYY-Www.md files are preserved legacy journals. Search can retrieve them, but their contents may mix speakers and past interpretations. Open the original passage before quoting it. Never add new material to frozen legacy files.
