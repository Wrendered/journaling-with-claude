# Claude-Guided Sessions

> Copy-paste-ready prompts that turn the couple/ exercises into Claude-facilitated sessions. Use them solo (for individual prep) or together (for joint sessions).

---

## Why Use These

The materials in `couple/` work fine on their own — print them, talk, write things down. But if you and your partner both work fluently with Claude, you may prefer Claude as a facilitator: it keeps you on the question, asks clarifying follow-ups, captures outputs, and steps back when you need to talk without an AI in the room.

These prompts are designed for **flexible use:** Claude facilitates the structure, but you control the pace. The joint prompts include explicit "step away from the screen and talk for 10 minutes, then come back" moments.

## How to Use

1. **Solo prompts:** Each partner opens their own Claude session and pastes the prompt. Each does the work alone. Output is saved to a personal file.
2. **Joint prompts:** Sit down together. One person pastes the prompt into Claude. The session is collaborative. Output is saved to a *shared* file (something both of you can access).
3. **Back-and-forth:** The joint prompts have explicit "step away" moments built in. Use them. Claude is a facilitator, not a substitute for actually talking to each other.

---

## Where Outputs Go

- **Solo prep:** save to a personal file (each partner's own filesystem or notes app)
- **Joint outputs:** save to a shared location — shared Google Doc, Dropbox file, whatever you both can access. The prompt will ask where to save.
