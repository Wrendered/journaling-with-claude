# Monologue

Read [the shared memory contract](../../../docs/memory-contract.md) before the first capture, state update, or import in a session. Use AGENTS.md for privacy, attribution, and current-context precedence.

1. Read personal preferences and the current dated context. Stay in this conversation.
2. Save each message immediately using the hook receipt or manual capture in the memory contract. Preserve typos, line breaks, uncertainty, and contradictions. Saving must not wait until the user finishes.
3. While they are continuing, acknowledge briefly. Do not summarize, search their history, assign homework, or ask a sequence of questions. Silence between messages is not evidence they finished. If they ask a question mid-dump, answer it briefly and let them continue.
4. Once they say they are done or ask you to reflect, give a short, faithful playback. Ask at most one useful question. Do not turn pain into a performance plan unless that is what they want.
5. Save any delivered reflection separately as assistant_summary or assistant_framing. Never pre-save a response that has not been sent. If delivery cannot be verified, leave it out. Their later agreement is a new user record, not retroactive authorship.
6. If a decision or relationship status changed, add an assertion with an exact source passage and event date. Leave the reasons unresolved if they have not stated them. Keep ambivalence intact.
7. Connect to earlier writing only when it helps the reflection after capture. Cite source passages with dates and authorship. Rebuild views after recording changes.

Success: the original words are saved before processing, the user feels free to keep talking, and interpretation is visibly separate. A heart dump needs no title, tags, mood score, or finished conclusion from the user.
