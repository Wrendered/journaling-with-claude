# Compare approaches

Read [conversation design](../../../docs/conversation-design.md) and the
[framework index](../../../frameworks/_index.md). Follow the memory contract for
personal text; public research and personal application remain separate.

Use the user's question and desired experience to select two or three genuinely
different options. A request for broad coverage can justify more. Explain what each
would attend to, a possible conversational move, what it could miss, and evidence
limits. Read only the relevant cards; verify unfamiliar or changing claims with
primary sources. Distinguish a method's theory, clinical findings, and this chat adaptation.

If useful, illustrate each lens on the same user-supplied passage with explicitly
tentative wording. Do not turn multiple models into corroboration or decide which
interpretation is true. Let the user choose, reject, or combine aspects; an existing
preference can be used without another intake questionnaire.

When they want to continue exploring, use deep-dive and one coherent move. If they
want to design the system, perform the authorized repository work. Record actual
feedback in the private support wiki, without labeling the user by a modality.
